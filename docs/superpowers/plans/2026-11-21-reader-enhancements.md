# 阅读增强实现计划

1. 保留现有页面样式改动，扩展 Library 迁移。收藏独立保存已读与标签，使用 JSON 文件导入导出并校验版本、URL、数量和数据类型。
2. 提取阅读辅助组件，展示正文图片及代码入口。图片支持缩放与重置，代码支持复制。
3. 各站与列表类型分别保存内容和位置，刷新失败保留原内容。评论续读跨分页加载到稳定回复 ID，设置取消和页数边界。
4. 网页提供字号、查找、复制链接与外部浏览器入口，显示实际网页进度和失败信息。
5. V2EX 令牌可选保存至 AssetStore，恢复前验证，明确失效状态，退出时删除。Linux.do 依据官方接入规则说明实际依赖。
6. 扩展针对迁移、导入与内容提取的回归测试，运行现有测试和 assembleHap。记录真机待验项。
