# 栈里拾光 · Stack Glean

**技术好内容，一处慢慢读。**

栈里拾光是一款面向鸿蒙手机的技术社区阅读器，使用 ArkTS + ArkUI 开发。你可以阅读 V2EX、Linux.do，也可以在应用内浏览其他技术站点，把碎片时间留给值得读的内容。

“栈”来自开发者熟悉的技术栈，也代表不断积累的知识；“拾光”是在日常间隙里，拾起值得阅读、思考和留存的内容。

> 当前版本：**0.1.0 开发验证版**。已完成本机构建、开发签名和连接手机的安装验证；尚未完成完整真机验收与应用市场发布。Linux.do 原生账号登录仍未接通。

## 功能概览

| 功能 | 当前支持情况 |
| --- | --- |
| 游客阅读 | 首次同意隐私说明后，可浏览站点允许公开访问的内容 |
| 原生信息流 | V2EX 最新 / 热门，Linux.do 最新 / Top |
| 主题与评论 | 原生页面加载正文、评论及后续回复 |
| 富文本 | 基础 HTML 排版、HTTPS 图片、代码、引用和表格；过滤远程脚本、事件属性与不安全地址 |
| 阅读设置 | 字号调整、深色阅读；正文和评论按设备字体单位换算显示 |
| 稍后读与历史 | 本机保存，支持按滚动偏移恢复阅读位置 |
| 离线阅读 | 最多缓存 20 个匿名主题；图片不保证离线可用 |
| 原站降级 | 可选开启加载失败后自动打开对应原站网页 |
| 站点管理 | 显示数量、单站开关、上下排序及恢复默认，重启后保留 |
| 关于我们 | 名称由来、应用介绍、隐私与非官方声明 |

原生部分定位为只读客户端，暂不提供发帖、回复、点赞或原站收藏同步。应用内打开的原站网页保留原站自身功能。

## 支持的站点

| [SegmentFault 思否](https://segmentfault.com/) | 原站网页 | 技术问答与经验交流 |

| [开源中国](https://www.oschina.net/) | 原站网页 | 开源项目与社区动态 |
| [GitHub Trending](https://github.com/trending) | 原站网页 | 热门开源仓库 |

## 使用方法

### 阅读与切换站点

主页上方站点栏支持左右滑动。V2EX、Linux.do 打开原生信息流，其他站点打开应用内网页。“技术站点”页提供相同站点的浏览入口和本地搜索。

### 自定义显示数量和顺序

进入 **设置 → 站点管理**：

1. 用加减按钮选择最多显示的数量，范围为 0–8。
2. 开启或隐藏单个站点。
3. 用“上移 / 下移”调整顺序。
4. 需要时恢复默认站点设置。

应用先按顺序排除隐藏站点，再取前 N 个显示。**主页站点栏与技术站点页共用这份配置**；例如开启了 6 个站点、显示数量设为 2，页面仍只显示前 2 个。搜索仅作用于当前显示范围。

### 原生加载失败时打开原站

进入 **设置 → 阅读体验**，开启“失败时自动打开原站”（默认关闭）。列表加载失败时打开对应站点列表，正文或后续评论加载失败时打开对应主题。

返回应用不会自动重复请求，原站网页失败也不会循环降级。关闭降级时保留原生错误提示，主题读取失败可回退到已有离线缓存。

### 登录与本地记录

- **V2EX**：设置 → 账号 → 输入个人访问令牌。令牌只保存在内存，应用进程结束后需重新登录。最新 / 热门列表在登录后仍使用公开接口。
- **Linux.do**：设置 → 账号 → 原站登录 / 阅读。当前网页会话没有接入原生网络层，原生页面仍是游客权限。
- 稍后读和历史是应用本地数据，不自动同步至社区。当前暂不持久保存 V2EX 登录态正文、历史或稍后读，避免私有内容进入游客空间。

## 获取代码与构建

```powershell
git clone https://github.com/mengxiang1991/stack-glean.git
cd stack-glean
Copy-Item build-profile.example.json5 build-profile.json5
```

用 DevEco Studio 打开仓库根目录，按实际安装情况配置 SDK。若需 `local.properties`，内容示例为：

```properties
sdk.dir=C:/Program Files/Huawei/DevEco Studio/sdk
```

命令行构建：

```powershell
.\scripts\build.ps1
```

IDE 安装在其他位置时：

```powershell
.\scripts\build.ps1 -Studio 'D:\Tools\DevEco Studio'
```

脚本复用 IDE 内同版本工具链，并在项目目录生成模块链接和构建缓存；缺少 `build-profile.json5` 时会自动从模板复制。脚本支持的是当前 Windows 工具布局，不能保证适用于其他 IDE 版本或操作系统。

产物目录：`entry/build/default/outputs/default/`。

- 未配置签名：`entry-default-unsigned.hap`，不能直接用于正常真机安装。
- 配置签名后：`entry-default-signed.hap`，可安装到开发签名允许的设备。

### 签名与真机运行

1. 手机开启开发者模式与调试，通过 USB 或已配对的无线调试连接电脑。
2. 在 DevEco Studio 的 Project Structure → Signing Configs 中登录开发者账号，配置本机开发签名。
3. 检查构建产品是否关联签名：`app.products` 中的 `signingConfig` 必须与 `app.signingConfigs` 的名称一致。
4. 选择 `entry` 和目标手机，点击 Run 编译、安装并启动。

如果提示 `9568320 / no signature file`，先确认安装的是签名包，并检查上述关联。仅生成签名材料而未关联构建产品，仍可能输出未签名包。

实际 `build-profile.json5`、`local.properties`、证书、私钥、IDE 缓存与 HAP 产物均已加入忽略规则。**不要将签名密码、访问令牌或开发者证书提交到仓库。** 克隆代码不会获得原开发者的签名或账号。

## 项目结构

```text
AppScope/                         应用标识、名称与图标
entry/src/main/
  ets/
    entryability/                 应用入口
    pages/Index.ets               阅读、站点、设置及原站浏览界面
    domain/                       主题模型、站点配置与富文本过滤
    data/                         社区请求适配与本地存储
  resources/                      页面、颜色与文字资源
  module.json5                    模块信息与网络权限
hvigor/                           构建配置
scripts/build.ps1                 Windows 构建脚本
tests/core.cjs                    数据层固定样本测试
build-profile.example.json5       不含签名的构建模板
harmony-reader-plan.html          早期技术方案与交互原型
VALIDATION.md                     分阶段验证记录
```

客户端通过 HarmonyOS 网络 API 直接访问社区；当前没有自有后端。原生页面和 Web 页面是两条独立的阅读路径，不共享原生账号授权。

## 已知限制

- Linux.do 原生账号认证未完成。遇到接口限制或网页验证时，可开启原站降级。
- 富文本中的站点特有互动、完整引用跳转和复杂嵌入仍需原站查看；图片不保证离线可用。旧纯文本缓存需联网重载。
- 阅读进度使用滚动偏移，内容或字号变化可能影响定位准确性。
- 本地存储采用有数量边界的 Preferences 实现，尚未迁移至规划中的关系数据库。
- V2EX 最新 / 热门接口提供有限列表，不支持该列表的无限分页；Linux.do Top 与 V2EX 热门的排序含义不同。
- 内嵌原站页面的内容、语言、登录流程与网络可用性由原站决定。
- 仍有 SDK 异常处理相关编译提示；尚未完成系统性真机性能、无障碍和发布审核验收。

## 隐私与内容归属

应用原生部分只申请网络权限，不包含自有广告或统计 SDK。站点页在点击后加载对应网站，原站页面可能加载其自身第三方服务，遵循原站隐私规则。

阅读记录和设置保存在本机；V2EX 令牌当前仅在内存使用。网页 Cookie 由系统 Web 组件管理，可在设置 → 数据管理中清除；这不等同于清除网站所有类型的本地数据。

栈里拾光是非官方阅读工具，与所列社区不存在官方隶属关系。文章、图片及其他内容归原作者或原站所有，请遵守各站规则，不绕过访问权限。
