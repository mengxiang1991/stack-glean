# 栈里拾光 · HarmonyOS 原生阅读器

ArkTS + ArkUI，单 entry 模块，面向手机。当前为 **0.1.0 开发验证版**，不是已完成上架的产品。

## 已实现

- 首次隐私说明与同意后联网，默认游客使用。
- V2EX 最新/热门、主题和分页回复；V2EX 个人访问令牌身份验证与账号态主题读取。
- Linux.do 游客列表、主题、按 Discourse post stream 补齐回复。
- 正文与评论使用白名单富文本渲染，支持基础 HTML 排版、HTTPS 图片、代码、引用和表格；支持稍后读、历史和阅读偏移恢复。
- 最多 20 个匿名主题的离线缓存，网络失败时回退缓存。
- 字号、深色阅读、清理缓存、清理阅读历史。
- 原站 Web 浏览及 Linux.do 原站登录入口。
- 设置中的“失败时自动打开原站”（默认关闭）：原生列表、正文或评论请求失败后打开对应原站网页，网页失败不触发循环降级；返回应用不自动重试。
- “技术站点”入口：掘金、思否、InfoQ、开源中国、GitHub Trending、Hacker News，以及 V2EX/Linux.do 原站。支持本地搜索，点击后才联网加载；新增站点为 Web 嵌入，不是原生聚合 API。
- 设置 → 技术站点显示与顺序：可选 0–8 个显示上限，单站开关、上移/下移、恢复默认；隐藏后按排序补足到数量上限，设置自动保存。主页站点栏与技术站点页使用同一配置；主页可横向滑动选择。搜索仅搜索已显示站点。
- 设置首页按站点管理、阅读体验、账号、数据管理、关于我们分组；关于我们展示“栈里拾光”的名称含义、应用介绍与非官方声明。设置子页支持页内和系统返回。

## 必须了解的限制

- **Linux.do 原生账号登录尚未接通**。原站 Web 登录不会自动授权原生接口；界面已明确提示。站点限制或网页验证通过原站阅读，不能视为原生接入成功。
- V2EX 令牌仅保存在内存；重启应用后重新登录。登录态正文、历史、稍后读不落盘，避免私有数据进入游客空间。后续需要实现系统安全凭据存储与按账号隔离的数据库。
- 富文本已接入；图片不提供离线保证，站点特有互动组件、引用跳转和复杂嵌入仍需原站查看。旧纯文本缓存需联网重载。手机排版尚待验证。
- 进度使用滚动偏移；内容更新导致高度变化时可能偏移，后续升级稳定内容块/回复锚点。
- 首版使用有容量上限的 Preferences 存储，不是规划中的完整关系数据库实现；数据量扩大前需迁移。
- V2EX 公开 latest/hot 为有限列表，不提供虚假的首页分页。Linux.do 热门对应 top，排序与 V2EX 不保证一致。
- 独立原站页面允许用户使用原站功能，本应用原生部分不实现发帖、点赞或回复。
- 尚未完成真机 UI/性能测试、真实账号认证测试与商店发布审核。

## 打开与构建

从 GitHub 克隆后，先复制 `build-profile.example.json5` 为 `build-profile.json5`，再用 DevEco Studio 打开工程。命令行构建脚本也会在缺失时自动复制。实际 `build-profile.json5` 包含本机开发签名，已被 Git 忽略，不上传证书路径或签名密码。请在本机自行配置开发签名与 SDK 路径。

1. DevEco Studio → Open，打开 `D:\Project\v2ex`。
2. SDK 使用当前安装的 HarmonyOS 26.0.0；最低兼容配置 `6.0.0(20)`。需在目标手机验证实际系统/API兼容性，不根据营销系统名称推断 API。
3. SDK 路径由本地 `local.properties` 配置，不提交到版本库。
4. 命令行无网络构建（复用安装包内同版本 Hvigor）：

   ```powershell
   .\scripts\build.ps1
   ```

   脚本默认 DevEco 路径 `C:\Program Files\Huawei\DevEco Studio`，可用 `-Studio` 覆盖。构建缓存和模块链接只写项目目录。

5. 未配置签名时输出 `entry/build/default/outputs/default/entry-default-unsigned.hap`。此包不能直接当成已签名安装包使用。

## 真机运行（需本人操作账号）

1. 手机开启开发者模式与 USB 调试，连接电脑并确认调试授权。
2. DevEco Studio 打开 Project Structure → Signing Configs，登录华为开发者账号，为当前手机配置开发签名。
3. 确认包名 `com.yueliu.reader`，再选择手机运行 entry。包名为暂定，上架前需确认归属与唯一性。
4. 不要把私钥、证书密码、令牌或个人开发者资料提交到仓库。

## 测试

```powershell
node tests/core.cjs
```

测试直接加载实际 `.ets` 数据层，经本机 DevEco 自带 TypeScript 转译并替换网络传输；覆盖文本清理、DTO 映射、有限列表、令牌与游客隔离、Discourse 剩余回复、HTTP 错误及资源释放。这不能代替 ArkTS 编译和真机验收。
